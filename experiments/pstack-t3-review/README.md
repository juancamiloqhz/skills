# Archived pstack T3 review prototype

This experiment informed jstack's orchestration design. It is research material, outside the installable skill catalog. No workflow is enabled by reading this archive.

[`PROTOTYPE.md`](./PROTOTYPE.md) preserves the original `skills/pstack-t3-review/SKILL.md` bytes under a non-discoverable filename. Its original frontmatter, instructions, and [`agents/openai.yaml`](./agents/openai.yaml) are retained as prototype artifacts. Relative reference paths still resolve. The [T3 reference](./references/t3-orchestration.md) records the experiment's dispatch contract; use current runtime schemas for any future implementation.

The [upstream reference](./references/upstream.md) pins Lauren Tan's pstack Arena adaptation and its scope. The original [MIT notice](./LICENSE) is retained.

## Evidence and limits

- [Manual panel](../../evaluations/pstack-t3-review.md): two independent candidates, a fresh judge, and a parent synthesis for a synthetic queue problem.
- [Fresh-parent panel](../../evaluations/pstack-t3-review-parent.md): a separate coordinating agent ran the panel for a synthetic webhook problem.

The second evaluation disclosed the rubric to candidates. The archived instructions contain the later correction, which has not been behaviorally rerun. Historical receipts and outputs retain their original file paths and model settings; they do not certify current model availability, provider-effective reasoning settings, or operating-system read-only isolation.

This prototype is a possible input to a future Arena adapter. It is not the Investigation/how workflow proposed for `juan-mode`. See the [current implementation plan](../../research/pstack-t3-implementation-plan.md) before continuing implementation.
