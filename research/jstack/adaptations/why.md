## Preserved jstack decisions

Keep standalone invocation and unchanged juan-mode activation, catalog-discovered setup, saved role/model/effort choices, explicit configuration handoff, task IDs, owned outputs and terminal checks. The approved shared setup investigation contract remains unchanged. No fallback model, automatic installation, application edit or external mutation is authorized by investigation. Actual capacity and demonstrated path ownership constrain concurrency; they do not eliminate independent source work.

The omitted `disable-model-invocation: true` is retained for the existing catalog-based calling route. The [invocation review](../evaluations/investigation-restoration/alignment-review/README.md#invocation-metadata) checks official provider documentation and the installed Claude Code guard: a flagged helper is hidden from normal discovery and rejects agent invocation without the user naming it in the current turn. The tradeoff is continued eligibility for automatic model selection, unlike pstack. This is a concrete compatibility exception, not evidence of identical provider behavior. Complete explicit/workflow invocation across all providers remains untested. Other Cursor-specific dispatch fields and `.mdc` defaults are replaced by the configured T3 contract.

## Remaining differences from the exact source

- Discovery uses the current tool catalog and actual read schemas instead of Cursor's `mcps/` directory. Local Git and forge access are checked separately. Unavailable history, tools and out-of-scope sources produce coverage gaps, never fabricated searches.
- The source's one-investigator-per-category and one-source/MCP-per-investigator rules are restored. The prior expansion into multiple tasks within a category is removed. Upstream leaves source selection underspecified when a category has multiple candidates; this change preserves that limitation and the existing actual-search coverage reporting rather than choosing a new algorithm.
- Preserve the source's high irrelevance threshold and rare inline exception after all seven categories are checked for redundancy. If no source is readable, return an incomplete coverage map instead of empty delegates. Scope restrictions are an additional explicit skip reason required by actual authorization.
- Source-specific tool and schema names remain illustrative. The restored methods, traps, source inventory and return fields remain. The source index requires actual read-capability and schema checks before using examples. It does not claim current connector compatibility.
- Investigator excerpts may be short quotes or accurate paraphrases within applicable quotation limits, with precise locations. Source-specific return lists reflect the same requirement. Broad searches stay inside assigned project/source scope; cross-source leads return to their owner.
- Sentry uses existing readable Seer analysis only. Triggering a new external analysis is outside the shared read-only contract; primary event investigation proceeds without it.
- The synthesizer may write only its assigned temporary findings artifact, as the shared contract allows. Its citation checks, exact output structure, seven-category coverage and seven-item final quality check are restored. Missing Git/forge access is reported rather than described as impossible.
- The full epistemics and incident/postmortem content is unchanged. Other formatting differences add blank lines, table spacing, text fence labels and a lint directive without changing the algorithms.
