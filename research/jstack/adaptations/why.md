## Remaining differences from the exact source

- Discovery uses the current tool catalog and actual read schemas instead of Cursor's `mcps/` directory. Local Git and forge access are checked separately. Unavailable history, tools and out-of-scope sources produce coverage gaps, never fabricated searches.
- The source's one-investigator-per-category and one-source/MCP-per-investigator rules are restored. The prior expansion into multiple tasks within a category is removed. Upstream leaves source selection underspecified when a category has multiple candidates; this change preserves that limitation and the existing actual-search coverage reporting rather than choosing a new algorithm.
- Preserve the source's high irrelevance threshold and rare inline exception after all seven categories are checked for redundancy. If no source is readable, return an incomplete coverage map instead of empty delegates. Scope restrictions are an additional explicit skip reason required by actual authorization.
- Source-specific tool and schema names remain illustrative. The source index requires actual read-capability and schema checks before using examples. It does not claim current connector compatibility. The four updated guides retain the audited source's remaining sections; code archaeology, incident context and Slack now match its bytes exactly.
- Investigator excerpts may be short quotes or accurate paraphrases within applicable quotation limits, with precise locations. Retained source-specific return lists reflect the same requirement. Broad searches stay inside assigned project/source scope; cross-source leads return to their owner.
- Sentry uses existing readable Seer analysis only. Triggering a new external analysis is outside the shared read-only contract; primary event investigation proceeds without it.
- The synthesizer may write only its assigned temporary findings artifact, as the shared contract allows. Its citation checks, exact output structure, seven-category coverage and seven-item final quality check are restored. Missing Git/forge access is reported rather than described as impossible.
- Epistemics remains unchanged. Incident/postmortem context now follows the audited three-bullet source. In the updated Sentry guide, only the existing read-only Seer substitution, text fence labels and list spacing differ from upstream. Other existing formatting differences add blank lines, table spacing and a lint directive without changing the algorithms.
