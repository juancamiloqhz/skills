# Worktree cleanup adaptation

Source procedure and auditor: `pstack/skills/poteto-mode/playbooks/worktree-cleanup.md` and `pstack/skills/poteto-mode/scripts/worktree-audit.sh` at `11713c683fe4add4fd403ea880580abbc9e0875f`. Local files are the [procedure](../../../skills/jstack/jstack-juan-mode/playbooks/worktree-cleanup.md), [shell entrypoint](../../../skills/jstack/jstack-juan-mode/scripts/worktree-audit.sh), [Python implementation](../../../skills/jstack/jstack-juan-mode/scripts/worktree_audit.py) and [input reference](../../../skills/jstack/jstack-juan-mode/references/worktree-audit.md).

The source's six steps, ordering, disk snapshots, advisory classification, usage review, loss gate, scoped pruning, conditional reclaimers and reply contract are retained. The [prior fidelity finding F7](../fidelity-audits/2026-10-13/foundation.md#f7-preserve-pending-tool-algorithms-and-resolve-upstream-contradictions-before-porting) and [delivery assessment](../juan-mode/delivery-inventory.md#worktree-cleanup) require correcting the source's unsafe assumptions before delivery. This is not authorization to clean the development repository.

| Source location | Difference | Requirement and verification |
| --- | --- | --- |
| Step 1 and shell parsing | Preserve the shell entrypoint, delegate portable parsing/classification to standard-library Python, and use NUL-delimited Git output. Include all registrations, not only branch-backed T3 refs. Escape paths in the table and expose JSON evidence. | The source's `awk '{print $2}'` loses spaces, and newline parsing cannot represent every valid Git path. Fixtures include spaces, a literal newline, detached HEAD, locks, missing paths and symlink replacement. Python replaces macOS-specific `stat`/`date`, shell regex/path interpolation and `jq` handling without installations. |
| Audit fetch and PR lookup | Make the audit a local read. The caller refreshes the explicitly chosen base and supplies scoped forge JSON when authorized. Missing base fails; missing PR evidence stays unknown. | The original script fetches while describing itself as read-only and assumes `origin/main`. The local default remains `origin/main`, with explicit override and recorded base commit. Fixtures prove missing-base failure and unchanged Git/file bytes. The live read used separately refreshed origin/main. |
| Transcript lookup, steps 1–3 | Replace automatic Cursor transcript discovery and four-day inactivity inference with project-scoped T3 bindings, task evidence and optional supplied usage records. Keep last-chat evidence unknown unless identified. Long inspections use configured read-only judgment children. | T3 does not expose pinned/active state through Git or branch inventory alone. Native metadata verified the current root binding; fixture usage and PR snapshots are explicitly simulated. Matching HEAD does not make a snapshot a live lock. Full pin discovery and transcript-review fanout remain unverified. |
| Dirty/PR buckets, steps 2–4 | Hold untracked and ignored content, current/main, locks, open PRs, active/unknown ownership and unmerged HEADs. Closed/merged PR labels cannot replace current ancestry or explicit squash/source proof. Only a clean merged row with supplied unused evidence becomes an advisory candidate. | The source calls untracked data scratch and accepts any PR record as a safety signal. Real Git fixtures cover valuable files, closed and merged PR labels over unmerged HEADs, stale ownership and content arriving after assessment. Detached commits require preserved reachability. |
| Step 5 | Recheck path, HEAD, content and ownership; prefer normal Git removal. Force, recursive deletion and stale metadata pruning require the exact assessed scope and loss decision. | Shared workspaces can change between audit and deletion. A symlink/reused path, ignored database or active checkout must not be erased by the source's unconditional force/rm fallback. The fixture removes one clean merged candidate without force and verifies every other worktree and the branch ref survive. Live user-worktree removal was not exercised. |
| Step 6 | Keep simulator operations conditional on macOS, available tools, requested target scope and inactivity. Broader caches/provider state require their own scope. | The executing host is Linux; macOS actions are inapplicable. A worktree request does not authorize all simulator or provider-state deletion. No macOS cleanup was executed. |
| Principles, reply and callers | Use portable principle names; distinguish proposed sizes from measured reclamation; disclose audit errors. Advertise 19 procedures and four pending. | Naming and evidence requirements. The shell returns 1 on invalid inventory/input and 2 on incomplete rows. Agent cases preserve report-only boundaries. No model-role, upstream-pin, manifest or package-license changes. |

Size, commit age, merge state, dirty categories, remote branch state, PR state, chat evidence and descending size order remain available. Numeric KiB plus JSON support exact evidence handling; age and size never prove abandonment. The source's `safe` label becomes `candidate` to preserve its stated advice-not-permission rule. The shell does not replace live T3 or forge verification with a new scheduler or implicit provider invocation.
