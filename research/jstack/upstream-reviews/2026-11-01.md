A port must replace the complete procedure and supporting callers, not merely rename the output headings. Scratch execution requires permission within the requested write boundary; a strict no-writes request must report the affected execution incomplete.

**Arena and setup** change different-family judging from preference to a hard eligibility rule, exclude inheritance aliases from judging, use configured order, and permit an explicit no-judge result. Upstream also drops/replaces rejected runner seats and tries default pools. An excluded inherited judge does not authorize changing models.json.

**Automation** changes Autopilot-stack from mandatory linear-stack/root-owned topology to Autopilot-full without merging, stacking only real dependencies. Opening a PR drops unconditional Interrogate, retaining deslop/no-comments. Test this cluster together rather than leaving inconsistent ownership rules.
