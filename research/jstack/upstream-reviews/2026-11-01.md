## Material comparisons and retained differences

**Interrogate** removes all four prior reviewer/rubric/lead references. The new Frame/Fan out/Verify/Output entrypoint reuses Arena's runner setup and fan-out, skips its cross-judge/base/graft phases, reruns each adversary command and merges failures by root cause. A plan needs an actual prototype/probe. Jstack currently has a static read-only five-step review and four verdict buckets, with T3 execution support. A port must replace the complete procedure and supporting callers, not merely rename the output headings. Scratch execution requires permission within the requested write boundary; a strict no-writes request must report the affected execution incomplete.

**Arena and setup** change different-family judging from preference to a hard eligibility rule, exclude inheritance aliases from judging, use configured order, and permit an explicit no-judge result. Upstream also drops/replaces rejected runner seats and tries default pools. Jstack's saved fixed seats, two-seat startup rule, model options, whole-map validation and no silent fallback are intentional. Recommend the new judge semantics subject to user approval, using only authorized configured selections. Explicit caller requirements such as Architect's two distinct viable candidates still apply. An excluded inherited judge does not authorize changing models.json.

**Automation** changes Autopilot-stack from mandatory linear-stack/root-owned topology to Autopilot-full without merging, stacking only real dependencies. Babysit owner rules and plan templates change with it. Full adds rebases for known concurrent same-file changes, pushes each finished unit, exempts wording-only changes from another verifier, and limits blockers to demonstrated user bugs, failed gates or wrong shipped docs. Base-existing defects do not block unless copied or newly reached. Keep named user gates even if a generic policy would waive them; factual documentation errors still matter. Opening a PR drops unconditional Interrogate, retaining deslop/no-comments. Test this cluster together rather than leaving inconsistent ownership rules.

**Orchestrate** is now a 25-line owner/verifier supervision procedure. It removes ledger/init/frontier/inbox scripts, routes state through a Project tracker/store, uses events instead of loops, and gives PR owners branch topology. Current jstack still requires its adapted orch ledger, recoverable inbox, frontier, completion reconciliation and documented restoration. New source does not make those active local callers safe to delete immediately. A coordinated port must migrate runtime references, task/store contracts and test selection before retirement, retain old stores as history, and demonstrate pickup without inventing a T3 tracker/cloud/fork capability. Upstream's different-model retry does not override saved selections. Host-supported task replacement and parent-owned watches take precedence over Cursor Task options. Prior recovery evidence remains historical, not evidence for this replacement.

**Statechart** changes much more than a renderer. TLC reruns after removing broken rules, bounds later runs at 100,000 states, lists unchecked rules, and limits complete charts to 500 states. Quotient VIEW/SYMMETRY and constraint-bound paths need semantic tests. The entrypoint explicitly installs Java/TLC through mise on first use; rendering requests Pele 1.9.0 and SVG. The tree adds TypeScript stages, tests, corpus and fast-check 4.5.3, removing the earlier JavaScript scripts and tests. This review locates and assesses that replacement for adoption scope; it does not claim a correctness audit of the implementation or execute/download any of it.
